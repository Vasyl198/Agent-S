```python
@dataclass(frozen=True)
class PatternGrading:
    size_from: str
    size_to: str
    
    # rules: role → (dx, dy)
    point_rules: Dict[str, Tuple[float, float]]
    
    def get_rule(self, role: str) -> Tuple[float, float]
    def has_rule(self, role: str) -> bool
    def get_roles_with_rules(self) -> list[str]
    def to_dict(self) -> dict
```

📌 **правила по ролям, а не по координатам**
📌 **ML-friendly**

### 🧠 **RuleBasedGradingProcessor — СЕРДЦЕ ФАЗЫ**
**📁 `agent/fashion/pattern/processors/grading_processor.py`**
```python
class RuleBasedGradingProcessor:
    def process(self, pattern_model: PatternModel, grading: PatternGrading) -> PatternModel:
        # Использует семантику для применения правил
        new_points = self._apply_grading_rules(contour.points, semantics, grading)
        new_segments = self._create_new_segments(contour.segments, new_points)
        new_contour = Contour(new_segments, closed=contour.closed)
        
        # Возвращает новую модель с градацией
        return pattern_model.with_grading(grading).with_contour(new_contour)
```

📌 **КРИТИЧНО:**
- ❌ **не масштаб**
- ❌ **не угадывание**
- ✅ **семантика → правило → движение**
- ✅ **возвращает новую модель**

### 🧠 **Обновленный PatternModel**
**📁 `agent/fashion/pattern/model.py` (ОБНОВЛЕН)**
```python
@dataclass(frozen=True)
class PatternModel:
    contour: Contour
    meta: PatternMeta
    semantics: Optional[PatternSemantics] = None
    dimensions: Optional[PatternDimensions] = None
    grading: Optional[PatternGrading] = None  # НОВОЕ в ФАЗЕ 3.3
    manufacturing: Optional[Dict[str, Any]] = None
    
    # Новые методы для работы с градацией
    def has_grading(self) -> bool
    def with_grading(self, grading) -> 'PatternModel'
    def with_contour(self, contour) -> 'PatternModel'
```

❗ **Градация как immutable данные**
❗ **Безопасное создание новых моделей**
